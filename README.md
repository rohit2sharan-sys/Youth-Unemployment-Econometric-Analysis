# Cross-Country Determinants of Youth Unemployment
### Econometrics | Python | World Bank WDI

## 1. Project Overview
This research project examines the determinants of youth unemployment across **117 countries** using cross-country data from the **World Bank's World Development Indicators (WDI)**.

The study applies econometric modelling and diagnostic techniques to investigate the relationship between labour market indicators and youth unemployment.

## 2. Research Objectives
- Examine the key determinants of youth unemployment across countries.
- Analyse the relationship between labour force participation and youth unemployment.
- Apply econometric techniques to estimate and validate regression models.
- Derive empirical insights into cross-country labour market differences.

## 3. Dataset
- **Source:** World Bank – World Development Indicators (WDI)
- **Coverage:** 117 countries
- **Nature:** Cross-country economic data
- **Dependent Variable:** Youth Unemployment

## 4. Methodology & Econometric Tools
Applied 27 econometric tools and techniques, including:

- Ordinary Least Squares (OLS)
- Breusch–Pagan Test
- Box–Tidwell Test
- Variance Inflation Factor (VIF)
- Ridge and Lasso Regression
- Ordinal and Multinomial Logistic Regression

These techniques were used for estimation, model diagnostics, robustness analysis and exploring alternative specifications.

## 5. Key Findings
The log-OLS model indicates that a **1-percentage-point increase in labour force participation is associated with approximately 3.5% lower youth unemployment**, holding other included factors constant.

This represents an empirical association and should not be interpreted as a causal effect.
